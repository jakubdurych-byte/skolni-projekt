Formuláře (Forms)

Formuláře jsou srdcem interaktivity každého webu. Slouží k registraci, přihlašování, anketám nebo odesílání zpráv. Vyzkoušej si jednotlivé typy políček, párování popisků i validaci.

3.1 Textová pole, e-mail, heslo a atribut required
HTML Editor Živý náhled
Výsledek v prohlížeči
Klíčová pravidla:
  • for="..." a id="..." Propojí <label> s <input>. Kliknutí na text popisku okamžitě aktivuje políčko (skvělé na mobilu!).
  • name="..." Klíč, pod kterým server data obdrží (např. email=novak@skola.cz).
  • required Prohlížeč nepustí uživatele dál, dokud políčko nevyplní.
  • placeholder Dočasný šedý text s nápovědou pro uživatele.
3.2 Radio přepínače, Checkboxy a roletka (<select>)
HTML Editor Živý náhled
Výsledek v prohlížeči
Rozdíly mezi prvky:
  • type="radio" Přepínač – uživatel smí vybrat pouze 1 možnost. Všechny přepínače ve stejné skupině musí mít stejný atribut name!
  • type="checkbox" Zaškrtávátko – každé pole je nezávislé, uživatel může zaškrtnout 0, 1 nebo všechny.
  • <select> a <optgroup> Vytváří roletové menu rozdělené do tématických skupin voleb.
  • <textarea> Textové pole pro dlouhý víceřádkový text (na rozdíl od jednořádkového inputu).
3.3 Seskupování polí (<fieldset>, <legend>) a nahrávání souborů
HTML Editor Živý náhled
Výsledek v prohlížeči
Vysvětlení značek:
  • <fieldset> Logicky seskupuje související pole do vizuálního rámečku.
  • <legend> Popisek / titulek rámečku fieldsetu.
  • type="file" Umožní uživateli vybrat soubor z počítače či mobilu.
  • readonly Políčko lze přečíst a hodnota se odešle, ale uživatel text nemůže přepsat.
3.4 Moderní HTML5 vstupy (date, time, color, range)
HTML Editor Živý náhled
Výsledek v prohlížeči
Výhody HTML5 vstupů:
  • type="date" a type="time" Zobrazí systémový kalendář i časovač bez nutnosti psát jediný řádek JavaScriptu.
  • type="color" Otevře paletu barev a vrátí hexadecimální hodnotu barvy (např. #0071e3).
  • type="range" Posuvník. Pomocí min, max a step nastavíš rozsah a velikost kroku.

📚 Přehled všech tagů a atributů pro formuláře

Všechny pojmy pro písemky a zkoušení z formulářů.

Značka / Atribut Typ Význam a školní popis Příklad použití
<form> Párový tag Obal pro celý formulář. Obsahuje atributy action a method. <form action="uloz.php" method="POST">
<input> Nepárový tag Univerzální formulářové pole. Typ určuje atribut type="...". <input type="text" name="jmeno">
<label> Párový tag Textový popisek spárovaný se vstupem přes for="id". <label for="jmeno">Jméno:</label>
<select>, <option> Párové tagy Rozbalovací roletové menu s jednotlivými možnostmi. <select><option>1.A</option></select>
<textarea> Párový tag Víceřádkové textové pole pro dlouhé texty a zprávy. <textarea rows="4"></textarea>
<button> Párový tag Tlačítko formuláře: type="submit" (odeslat), type="reset" (vymazat). <button type="submit">Odeslat</button>
<fieldset>, <legend> Párové tagy Vizuální rámeček pro seskupení souvisejících polí s titulkem. <fieldset><legend>Osobní údaje</legend>...
name Atribut Klíčové jméno, pod kterým server hodnotu pole přijme. name="telefon"
placeholder Atribut Šedá nápověda uvnitř vstupního pole před zapsáním textu. placeholder="např. Jan Novák"
required Atribut Určuje, že pole je povinné pro odeslání. <input required>
disabled vs readonly Atributy Disabled pole je neaktivní a neodesílá se; readonly je jen pro čtení a odesílá se. <input readonly>
