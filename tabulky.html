Tabulky (Tables)

Tabulky slouží k zobrazení strukturovaných dvourozměrných dat. V HTML se tabulka staví výhradně po řádcích (shora dolů). Zde si procvičíš základní stavbu, sémantiku i pokročilé slučování colspan a rowspan.

2.1 Klasická tabulka se známkami a učiteli
HTML Editor Živý náhled
Výsledek v prohlížeči
Základní stavební kameny:
  • <table> Obaluje celou tabulku.
  • <caption> Titulek nebo nadpis tabulky (vždy jako první prvek v <table>).
  • <tr> Table Row – řádek tabulky. Každý řádek obsahuje buňky <th> nebo <td>.
  • <th> Table Header – záhlaví sloupce (text je tučný a centrovaný).
  • <td> Table Data – běžná buňka pro data zarovnaná vlevo.
2.2 Slučování buněk: colspan (vodorovně) a rowspan (svisle)
HTML Editor Živý náhled
Výsledek v prohlížeči
Zlatá pravidla slučování:
  • colspan="N" Sloučí N sloupců vodorovně. V aktuálním řádku musíš ubrat N-1 buněk <td>.
  • rowspan="N" Sloučí N řádků svisle dolů. V následujících N-1 řádcích na této pozici buňku <td> vynecháš!
2.3 Sémantická tabulka (<thead>, <tbody>, <tfoot>) a atribut scope
HTML Editor Živý náhled
Výsledek v prohlížeči
Proč používat sémantické bloky:
  • <thead> Hlavička tabulky. Tiskárny a čtečky obrazovky ji opakují na každé vytištěné stránce.
  • <tbody> Tělo s daty. V jedné tabulce může být i více <tbody>.
  • <tfoot> Souhrnná patička (součty, průměry). Vždy se vykresluje vespod tabulky.
  • scope="col|row" Určuje, zda hlavička <th> patří celému sloupci nebo řádku (důležité pro hlasové čtečky).
2.4 Skupiny sloupců (<colgroup> a <col>)
HTML Editor Živý náhled
Výsledek v prohlížeči
K čemu slouží colgroup:
  • <colgroup> Umožňuje nastavit šířky, pozadí nebo ohraničení pro celé sloupce najednou, aniž bys musel psát styl ke každé jednotlivé buňce <td>.

📚 Přehled všech tagů a atributů pro tabulky

Všechny pojmy pro písemky a praktické testy.

Pojem / Značka Typ Popis a školní využití Příklad zápisu
<table> Párový tag Základní kontejner ohraničující celou tabulku. <table>...</table>
<caption> Párový tag Nadpis / popisek tabulky zobrazený nahoře. <caption>Rozvrh</caption>
<tr> Párový tag Table Row – jeden vodorovný řádek tabulky. <tr>...</tr>
<th> Párový tag Table Header – záhlavní buňka (tučný text na střed). <th>Jméno</th>
<td> Párový tag Table Data – běžná datová buňka. <td>Petr</td>
colspan Atribut th / td Sloučení sloupce vodorovně přes N pozic. <td colspan="2">
rowspan Atribut th / td Sloučení řádku svisle dolů přes N řádků. <td rowspan="2">
<thead> Párový tag Zabaluje řádky hlavičky tabulky. <thead><tr>...</tr></thead>
<tbody> Párový tag Zabaluje tělo tabulky s datovými řádky. <tbody><tr>...</tr></tbody>
<tfoot> Párový tag Zabaluje souhrnnou patičku tabulky. <tfoot><tr>...</tr></tfoot>
<colgroup>, <col> Párový / nepárový Definice sloupcových vlastností (šířky, barvy). <col style="width:50%">
scope Atribut pro <th> Určuje rozsah hlavičky: "col" (sloupec) nebo "row" (řádek). <th scope="col">
