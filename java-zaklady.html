Základní struktura, typy a pole v Javě

Java je silně typovaný, kompilovaný jazyk běžící na virtuálním stroji JVM (Java Virtual Machine) podle hesla "Write Once, Run Anywhere". Každý program musí být uzavřen ve třídě se vstupní metodou main.

☕ Klíčové pojmy jazyka Java (Maturitní tahák)

Co znamená každé slovo v definici public static void main?

Klíčové slovo Význam Proč je nutné v metodě main
public Modifikátor přístupu Metoda je viditelná odkudkoliv, JVM ji může zavolat zvenčí.
static Statický člen třídy Metoda patří třídě, nikoliv instanci. JVM nemusí vytvářet objekt třídy, aby program spustil.
void Návratový typ Metoda nevrací žádnou hodnotu (návratový kód předává operační systém jiným způsobem).
String[] args Parametry příkazové řádky Pole textových argumentů předaných programu při spuštění v terminálu.
