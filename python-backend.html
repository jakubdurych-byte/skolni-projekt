Propojení HTML formuláře s Pythonem

Když uživatel vyplní formulář v HTML a klikne na Odeslat, prohlížeč vytvoří HTTP POST požadavek a pošle data na server. Zde se dozvíš, jak tato data jednoduše přečíst a zpracovat v Pythonu.

🔄 Jak probíhá komunikace (Klient → Server → Klient)

💻
1. Prohlížeč (HTML Klient)

Uživatel vyplní <form method="POST" action="/zpracuj"> a klikne na Odeslat.

⚡
2. HTTP Síťový přenos

Data putují po síti jako textové dvojice: jmeno=Jan&email=jan@skola.cz.

🐍
3. Python Server

Python data přečte, uloží do databáze a pošle zpět HTML stránku s potvrzením.

server_priklad.py (reálný kód v Pythonu) 
# Ukázka ze souboru server_priklad.py ve tvé složce:
from http.server import HTTPServer, BaseHTTPRequestHandler
import urllib.parse

class SkolniHandler(BaseHTTPRequestHandler):
    def do_POST(self):
        # 1. Zjistíme velikost odeslaných dat a přečteme je
        length = int(self.headers.get('Content-Length', 0))
        body = self.rfile.read(length).decode('utf-8')

        # 2. Rozbalíme odeslaná pole formuláře
        data = urllib.parse.parse_qs(body)
        jmeno = data.get('jmeno', ['Neznámý'])[0]

        print(f"Student {jmeno} právě odeslal formulář!")

        # 3. Odešleme odpověď zpět do prohlížeče
        self.send_response(200)
        self.send_header("Content-type", "text/html; charset=utf-8")
        self.end_headers()
        self.wfile.write(f"<h1>Ahoj {jmeno}, Python přijal tvůj formulář!</h1>".encode('utf-8'))

# Spuštění na portu 8000
HTTPServer(('localhost', 8000), SkolniHandler).serve_forever()
Jak si to rovnou vyzkoušet:
  • Ve tvé složce projektu je připravený funkční skript server_priklad.py.
  • V terminálu spusť příkaz: python3 server_priklad.py
  • Otevři v prohlížeči adresu http://localhost:8000 a vyzkoušej si odeslat formulář do běžícího Pythonu!
