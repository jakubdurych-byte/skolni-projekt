CSS Styly, Box Model & Selektory

Zatímco HTML tvoří kostru stránky, CSS (Cascading Style Sheets) dodává barvy, písma, rozvržení a animace. Toto je klíčová látka pro každého, kdo se učí web a chystá se k maturitě z informatiky.

1. Způsoby vložení CSS do stránky
HTML Editor (můžeš přepisovat) Živý náhled
Výsledek v prohlížeči
Maturitní otázka: 3 způsoby vložení CSS
  • 1. Externí soubor <link rel="stylesheet" href="style.css"> v hlavičce <head>. Nejlepší a nejčistší praxe v praxi i u zkoušek!
  • 2. Interní blok <style> ... </style> přímo v hlavičce HTML dokumentu. Vhodné pro jednostránkové projekty.
  • 3. Řádkový (inline) Přímo v atributu <p style="color: red;">. Má nejvyšší prioritu, ale zhoršuje přehlednost kódu.
2. Krabičkový model (CSS Box Model)
HTML Editor Živý náhled
Výsledek v prohlížeči
Vysvětlení 4 vrstev Box Modelu:
  • 1. Content (Obsah): Samotný text, obrázek či video. Nastavuje se přes width a height.
  • 2. Padding (Vnitřní odsazení): Mezera mezi obsahem a rámečkem.
  • 3. Border (Rámeček): Čára ohraničující prvek (např. 2px solid #333).
  • 4. Margin (Vnější odstup): Volné místo kolem prvku, které ho odtlačuje od ostatních prvků.
  • box-sizing: border-box Maturitní chyták! Způsobí, že nastavená šířka width: 300px je konečná a padding s borderem ji už dále nezvětšují.
3. Flexbox – Moderní rozvržení prvků vedle sebe
HTML Editor Živý náhled
Výsledek v prohlížeči
Klíčové vlastnosti Flexboxu:
  • display: flex Zapne flexibilní chování. Prvky se automaticky poskládají do řádku vedle sebe.
  • gap: 12px Moderní zápis pro mezery mezi flexibilními položkami.
  • justify-content Zarovnává prvky v hlavní ose (center, space-between, flex-start).
  • align-items Zarovnává prvky na kolmé ose (na střed svisle: center).

📚 Přehled základních CSS vlastností a selektorů

Nezbytné znalosti pro testy i praktické úlohy.

Selektor / Vlastnost Typ Popis a význam Příklad zápisu
.nazev-tridy Třídní selektor Vybere všechny prvky s atributem class="nazev-tridy". Může být použit vícekrát. .tlacitko { color: red; }
#unikatni-id ID selektor Vybere jediný prvek s daným id="...". Má vyšší prioritu než třída. #hlavni-nadpis { font-size: 2rem; }
:hover Pseudotřída Styl, který se aktivuje při najetí myší na prvek. a:hover { text-decoration: none; }
margin vs padding Box model Margin je vnější odstup kolem prvku; padding je vnitřní odsazení od rámečku dovnitř. margin: 10px; padding: 15px;
rem / em / px Jednotky px je absolutní pixel; rem je relativní k základní velikosti písma dokumentu. font-size: 1.25rem;
