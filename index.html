public static void main Java Povinná vstupní metoda programu v Javě, kterou spouští virtuální stroj JVM. Java →
extends vs implements Java extends dědí od jedné třídy, implements implementuje rozhraní (interface). Java OOP →

LINQ (.Where / .Select) C# Integrovanný dotazovací jazyk v C# pro funkcionální filtrování a transformaci kolekcí. C# LINQ →
PRIMARY KEY SQL Unikátní sloupec (ID), který jednoznačně identifikuje každý řádek tabulky. SQL Tabulky →
INNER JOIN vs LEFT JOIN SQL INNER JOIN vrátí pouze řádky s oboustrannou shodou, LEFT JOIN vrátí všechny záznamy z levé tabulky. SQL JOIN →
git commit -m Git Vytvoří trvalý snímek verzí připravených souborů se zadanou popisnou zprávou. Git →
