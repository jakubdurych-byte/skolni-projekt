Responzivní design & CSS Animace

Dnes více než 60 % návštěvníků přistupuje na web z mobilních telefonů. Responzivní web se automaticky přizpůsobuje velikosti obrazovky pomocí Media Queries a nabízí plynulé přechody inspirované Apple rozhraním.

1. Media Queries: Změna rozvržení podle šířky okna
HTML & CSS Editor Živý náhled
Výsledek v prohlížeči
Pravidlo Media Queries:
  • @media (max-width: 768px) Aplikuje CSS pravidla pouze tehdy, pokud je šířka okna menší nebo rovna 768 pixelům (např. tablety a telefony).
  • viewport meta tag Bez značky <meta name="viewport" content="width=device-width, initial-scale=1.0"> v hlavičce by mobilní prohlížeč web zobrazil zmenšený jako na monitoru.
2. Plynulé Apple přechody (CSS transitions & transform)
HTML & CSS Editor Živý náhled
Výsledek v prohlížeči
Vysvětlení animací:
  • transition: transform 0.25s Určuje, které vlastnosti se mají animovat a jak dlouho má animace trvat.
  • transform: translateY(-6px) Posune prvek nahoru o 6 pixelů bez narušení okolních prvků.
