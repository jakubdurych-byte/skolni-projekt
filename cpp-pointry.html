Ukazatele (Pointers), Dereference a operátory new / delete

Ukazatel je proměnná, která jako svou hodnotu ukládá adresu v paměti RAM jiného objektu. Jde o nejznámější maturitní otázku z programování v C/C++, která odlišuje programátory od začátečníků.

1. Adresní operátor & a dereference ukazatele (*)
C++ Editor pointry.cpp
Terminal — g++ pointry.cpp && ./a.out
$ g++ pointry.cpp && ./a.out Hodnota proměnné: 42 Adresa v paměti (&cislo): 0x7ffd15a9e324 Hodnota ukazatele (ptr): 0x7ffd15a9e324 Hodnota na adrese (*ptr): 42 Po změně přes ukazatel má cislo hodnotu: 100 ✓ Process finished with exit code 0
2. Dynamická alokace paměti na haldě (Heap): new a delete[]
C++ Editor alokace.cpp
Terminal — g++ alokace.cpp && ./a.out
$ g++ alokace.cpp && ./a.out Dynamické pole vytvořeno na haldě: Index [0] = 1 Index [1] = 2 Index [2] = 1 Paměť byla úspěšně vrácena operačnímu systému. ✓ Memory Leak Check: 0 bytes leaked

🧠 Zásobník (Stack) vs. Halda (Heap) u maturity

Jak funguje paměť v počítači při běhu programu.

Vlastnost Zásobník (Stack) Halda (Heap)
Rychlost Extrémně rychlá (LIFO struktura přímo v CPU) Pomalejší (Vyhledávání volného bloku v paměti)
Velikost Omezená (při přetečení hrozí Stack Overflow) Velká (omezená pouze dostupnou fyzickou RAM počítače)
Správa paměti Automatická při opuštění bloku/funkce Manuální programátorem přes delete (v moderním C++ chytré ukazatele std::unique_ptr)
