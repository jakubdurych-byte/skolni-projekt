Návrhové vzory, Architektura MVC a REST API

Jak psát udržitelný kód na profesionální úrovni i k maturitní práci: návrhové vzory Gang of Four (Singleton, Factory, Observer), vrstvená architektura Model-View-Controller a interaktivní simulátor HTTP REST požadavků.

🚀 Interaktivní tester REST API & HTTP metod

Vyber HTTP metodu (GET, POST, PUT, DELETE), zadej koncový bod a sleduj odpověď serveru a HTTP stavové kódy.

Stav odpovědi (Status): 200 OK Content-Type: application/json

  "status": 200,

}

📡 Nejdůležitější HTTP stavové kódy (Status Codes)

200 OK Úspěch

Standardní odpověď na úspěšný GET požadavek.

201 Created Vytvořeno

Záznam byl úspěšně vytvořen (typicky po POST).

301 Redirect Přesměrování

Trvalé přesměrování na novou URL adresu (Moved Permanently).

400 Bad Request Chyba klienta

Požadavek má neplatnou syntaxi (chybný JSON těla).

401 / 403 Neautorizováno

401 = nepřihlášen, 403 = zakázáno (chybí administrátorská práva).

404 Not Found Nenalezeno

Hledaný zdroj nebo URL adresa na serveru neexistuje.

500 Internal Error Chyba serveru

Neošetřená výjimka v backendovém kódu.

502 / 503 Server nedostupný

Reverzní proxy (Nginx) nedostala odpověď nebo je server přetížen.

🧩 Návrhový vzor MVC (Model - View - Controller)

Oddělení dat a logiky od uživatelského rozhraní. Nejpoužívanější architektura webových frameworků (Django, Laravel, ASP.NET Core, Spring).

1. Model (Data & Databáze)

Stará se o data, validace, komunikaci s SQL databází přes ORM (SQLAlchemy, Entity Framework). Nemá tušení o tom, jak data vypadají na obrazovce.

2. Controller (Mozek aplikace)

Přijímá HTTP požadavky od uživatele, zavolá Model pro načtení/uložení dat a rozhodne, jaký View se má vrátit.

3. View (Zobrazení / Šablona)

Vykresluje HTML kód uživateli (nebo JSON formát pro frontend v Reactu/Vue). Neobsahuje žádnou složitou byznys logiku.

🏛️ 3 Klíčové návrhové vzory k maturitě (Singleton, Factory, Observer)

Kreační vzor

Singleton (Jedináček)

Zajišťuje, že třída má v celém běhu aplikace právě **jednu jedinou instanci** (např. připojení k databázi DatabaseConnection nebo konfigurační manažer). Konstruktor je soukromý (private).

Kreační vzor

Factory Method (Továrna)

Definuje rozhraní pro vytváření objektů, ale o samotné instanciaci rozhodují potomci (např. PaymentFactory.create('PayPal') vrátí instanci specifické platební brány).

Vzor chování

Observer (Pozorovatel / Eventy)

Objekt (Subject) udržuje seznam závislých pozorovatelů a při změně stavu je automaticky všechny notifikuje (základ pro addEventListener v JavaScriptu a GUI události).
