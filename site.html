Síťová infrastruktura

Model ISO/OSI, Protokoly TCP/IP a Výpočet podsítí

Základní pilíř IT maturity: 7 vrstev modelu OSI, rozdíl mezi spolehlivým TCP a rychlým UDP, princip směrování v internetu a interaktivní kalkulačka IPv4 podsítí (Subnetting).

🌐 Živá kalkulačka IPv4 podsítě (Subnet Calculator)

Zadej IP adresu a prefix masky (CIDR). Kalkulačka okamžitě spočítá Network ID, Broadcast, rozsah hostů i třídu sítě.

Adresa sítě (Network ID) 192.168.1.0
Všesměrové vysílání (Broadcast) 192.168.1.255
Maska sítě (Netmask) 255.255.255.0
Inverzní maska (Wildcard) 0.0.0.255
První použitelný host 192.168.1.1
Poslední použitelný host 192.168.1.254
Počet dostupných hostů 254
Třída sítě dle prvního oktetu Třída C (LAN)

📶 Referenční model ISO/OSI (7 Vrstev u maturity)

Hierarchické rozdělení síťové komunikace od fyzického kabelu po uživatelskou aplikaci.

L7
Aplikační vrstva (Application)
PDU: Data
HTTP, HTTPS, DNS, DHCP, SSH, FTP, SMTP
L6
Prezentační vrstva (Presentation)
PDU: Data
SSL/TLS šifrování, komprese, formáty JPEG, ASCII
L5
Relační vrstva (Session)
PDU: Data
Navázání a správa relace (Sockets, RPC, NetBIOS)
L4
Transportní vrstva (Transport)
PDU: Segment / Datagram
TCP (spolehlivý, handshake), UDP (rychlý stream)
L3
Síťová vrstva (Network)
PDU: Paket (Packet)
IPv4, IPv6, ICMP, ARP — Zařízení: Router (Směrovač)
L2
Linková vrstva (Data Link)
PDU: Rámec (Frame)
Ethernet, Wi-Fi (802.11), MAC adresy — Zařízení: Switch (Přepínač)
L1
Fyzická vrstva (Physical)
PDU: Bity (Bits)
UTP kabely (RJ-45), optická vlákna, rádiové vlny — Zařízení: Hub, Repeater

⚡ Rozdíl: TCP vs. UDP u zkoušky

Dva základní transportní protokoly internetu.

Vlastnost TCP (Transmission Control Protocol) UDP (User Datagram Protocol)
Spojení Spojovaný protokol (3-Way Handshake SYN, SYN-ACK, ACK) Nespojovaný protokol (Fire-and-forget bez potvrzení)
Spolehlivost Garantované doručení – ztracené pakety se posílají znovu Bez záruky – ztracený paket se zahodí a neřeší
Rychlost & Režie Větší režie hlavičky (20 bajtů), pomalejší Minimální režie (8 bajtů), maximální rychlost
Typické použití Web (HTTP/HTTPS), stahování souborů, e-maily, SSH Online hry pro více hráčů, živé video streamy, VoIP volání, DNS
