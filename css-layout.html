📐 Kdy použít Flexbox a kdy CSS Grid u maturity

Jedno z nejpopulárnějších maturitních témat moderního webdesignu.

Vlastnost Flexbox (Flexible Box) CSS Grid
Dimenze 1D (Jednorozměrný) – řídí buď řádek, nebo sloupec. 2D (Dvourozměrný) – řídí řádky i sloupce současně v mřížce.
Ideální pro Navigační lišty, tlačítkové řady, centrovaný obsah, zarovnání ikon s textem. Kompletní rozvržení webové stránky, Bento gridy, fotogalerie, dashboardy.
