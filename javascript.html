JavaScript & DOM manipulace

Zatímco HTML staví kostru a CSS šatí vzhled, JavaScript je mozek webu. Umožňuje reagovat na kliknutí, počítat data, měnit obsah stránky za běhu a kontrolovat formuláře. Vyzkoušej si živé miniprojekty!

1. Školní kalkulačka známkového průměru
HTML & JS Editor Živý náhled
Výsledek v prohlížeči
Jak to funguje v JavaScriptu:
  • document.getElementById() Vyhledá prvek v HTML podle jeho atributu id.
  • .split(',') Rozseká text podle čárky na pole jednotlivých známek.
  • .innerHTML Přepíše obsah vybraného HTML prvku novým textem nebo značkami.
2. Školní To-Do úkolníček (přidávání do seznamu <ul>)
HTML & JS Editor Živý náhled
Výsledek v prohlížeči
Vytváření elementů přes DOM:
  • document.createElement('li') Vytvoří za běhu v paměti nový HTML tag <li>.
  • ul.appendChild(li) Vloží nově vytvořenou položku na konec seznamu.
  • this.remove() Odstraní kliknutý prvek přímo ze stránky.
