22. Geometrická optika a přístroje

Šíření světla, zákon odrazu a lomu (Snellův zákon), úplný odraz, zrcadla, tenké čočky, oko a optické přístroje.

Geometrická optika modeluje světlo jako soustavu světelných paprsků, které se v homogenním prostředí šíří přímočaře. Platí zde princip nezávislosti chodu paprsků a zákon záměnnosti chodu paprsků.

1. Odraz a lom světla

📐 Základní zákony geometrické optiky

Index lomu prostředí: n = c / v (pro vakuum n = 1, voda ≈ 1,33, sklo ≈ 1,5)

Zákon odrazu: α = α' (úhel odrazu se rovná úhlu dopadu)

Snellův zákon lomu: sin α / sin β = n2 / n1 = v1 / v2

Mezní úhel (úplný odraz při přechodu do opticky řidšího prostředí): sin αm = n2 / n1

Úplný odraz světla se využívá v optických vláknech (internet), hranolech a odrazkách.

2. Zobrazování zrcadly a tenkými čočkami

📐 Zobrazovací rovnice a zvětšení

Zobrazovací rovnice: 1 / a + 1 / a' = 1 / f

Příčné zvětšení: Z = y' / y = −a' / a

Optická mohutnost čočky: φ = 1 / f [dioptrie, D = m-1]

  • Spojka (f > 0, φ > 0): Soustřeďuje paprsky, koriguje dalekozrakost.
  • Rozptylka (f < 0, φ < 0): Rozptyluje paprsky (vytváří vždy zdánlivý, zmenšený, přímý obraz), koriguje krátkozrakost.
  • Znaménková konvence: a' > 0 → obraz skutečný (lze zachytit na stínítko); a' < 0 → obraz zdánlivý.

3. Optické přístroje

Lupa (zvětšení Z ≈ d / f, kde d = 25 cm je konvenční zraková vzdálenost), mikroskop (soustava objektivu a okuláru) a dalekohled (Keplerův hvězdářský, Galileiho).

📐 Souhrn vzorců kapitoly

📐 Souhrn vzorců kapitoly

Snellův zákon lomu: sin α / sin β = n2 / n1 = v1 / v2  |  Mezní úhel: sin αm = n2 / n1

Zobrazovací rovnice čočky/zrcadla: 1/a + 1/a' = 1/f  |  Optická mohutnost: φ = 1/f [D]

Příčné zvětšení: Z = y' / y = −a' / a

🧮 Řešené příklady krok za krokem (3 vzorové úlohy)

Příklad 1: Lom světla při přechodu ze vzduchu do skla (Snellův zákon)

Lom světla
Zadání: Paprsek světla dopadá ze vzduchu (n1 = 1) na skleněnou desku (n2 = 1,5) pod úhlem dopadu α = 30°. Pod jakým úhlem β se světlo láme do skla?

1. Snellův zákon: sin α / sin β = n2 / n1 ⟹ sin β = (n1 / n2) · sin α.

2. Výpočet: sin β = (1 / 1,5) · sin 30° = (1 / 1,5) · 0,5 = 1/3 ≈ 0,3333 ⟹ β = arcsin(0,3333) ≈ 19,5°.

Příklad 2: Zobrazení spojkou (zobrazovací rovnice)

Čočky
Zadání: Předmět vysoký y = 4 cm stojí ve vzdálenosti a = 30 cm před tenkou spojkou o ohniskové vzdálenosti f = 20 cm. Vypočítejte obrazovou vzdálenost a', zvětšení Z a výšku obrazu y'.

1. Obrazová vzdálenost: 1/a' = 1/f − 1/a = 1/20 − 1/30 = (3 − 2)/60 = 1/60 ⟹ a' = 60 cm (obraz je skutečný).

2. Příčné zvětšení: Z = −a' / a = −60 / 30 = −2 (obraz je převrácený a 2× zvětšený).

3. Výška obrazu: |y'| = |Z| · y = 2 · 4 = 8 cm.

Příklad 3: Optická mohutnost brýlové čočky

Dioptrie
Zadání: Jakou ohniskovou vzdálenost f mají brýle na dálku s optickou mohutností φ = −2,5 D? O jaký druh čočky jde?

1. Vzorec: f = 1 / φ

2. Výpočet: f = 1 / (−2,5) = −0,4 m = −40 cm. Protože je f < 0, jde o rozptylku (korekce krátkozrakosti).
