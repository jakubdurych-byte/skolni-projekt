Databáze & SQL

Relační databáze, tabulky a příkazy CREATE, INSERT, UPDATE

SQL (Structured Query Language) je jazyk pro komunikaci s relačními databázemi (MySQL, PostgreSQL, SQLite, MS SQL). Umožňuje definovat strukturu databázových tabulek, vkládat řádky a spravovat data.

1. Tvorba tabulky (CREATE TABLE) a vkládání záznamů (INSERT INTO)
SQL Skript schema.sql
Terminal — sqlite3 skola.db
$ sqlite3 skola.db < schema.sql Tabulka 'studenti' vytvořena. 3 řádky úspěšně vloženy (Query OK, 3 rows affected). ✓ Databáze připravena bez chyb
2. Změna dat (UPDATE) a smazání záznamu (DELETE)
SQL Skript upravy.sql
Terminal — sqlite3 skola.db
$ sqlite3 skola.db < upravy.sql id|jmeno|prijmeni|trida|prumer 1|Jan|Novák|4.A|1.25 2|Petr|Svoboda|4.A|1.85 ✓ 1 řádek aktualizován, 1 řádek smazán

🔑 Klíče a integrita v relačních databázích

Maturitní otázka: Co je primární klíč a cizí klíč?

Pojem Zkratka Význam
Primární klíč PRIMARY KEY (PK) Sloupec (často ID), který jednoznačně identifikuje každý řádek v tabulce. Hodnota nesmí být prázdná (NOT NULL) a musí být unikátní.
Cizí klíč FOREIGN KEY (FK) Sloupec v tabulce, který odkazuje na primární klíč v jiné tabulce. Vytváří vazbu (relaci) mezi tabulkami (např. student patří do třídy).
DDL vs DML Kategorie SQL DDL (Data Definition: CREATE, ALTER, DROP) definuje strukturu. DML (Data Manipulation: SELECT, INSERT, UPDATE, DELETE) pracuje se samotnými daty.
