Verzování kódu, Git Workflow a příkazová řádka

Git je celosvětovým standardem pro verzování zdrojového kódu. Umožňuje vracet se v čase, spolupracovat v týmu bez přepisování cizí práce a bezpečně vyvíjet nové funkce ve větvích (branches).

1. Základní životní cyklus v Gitu (Init -> Add -> Commit -> Log)
Bash Script / Příkazy workflow.sh
Terminal — git status
$ git commit -m "feat: Přidání responzivního rozvržení" [main 7a8f3b1] feat: Přidání responzivního rozvržení 3 files changed, 142 insertions(+) create mode 100644 index.html create mode 100644 style.css create mode 100644 app.js ✓ 1 commit vytvořen na větvi main
2. Práce s větvemi (Branches) a slučování (Merge)
Bash Script / Větve branches.sh
Terminal — git merge
$ git merge feature-dark-mode Updating 7a8f3b1..9e42c08 Fast-forward style.css | 48 ++++++++++++++++++++++++++++++++++++++++++++++++ 1 file changed, 48 insertions(+) ✓ Větev úspěšně sloučena (Fast-forward)

🌳 3 Stavy souboru v Gitu (Maturitní tahák)

Základní zkoušková otázka: Jaký je rozdíl mezi Working Directory, Staging Area a Repository?

Zóna / Stav Popis Příslušný příkaz
1. Pracovní adresář (Working Tree) Fyzické soubory na vašem pevném disku, které právě editujete v editoru. Změny zatím Git neuchovává. git status (červené zbarvení)
2. Přípravná oblast (Staging Area / Index) Mezistupeň. Zde si vybíráte konkrétní změny a soubory, které chcete zabalit do příští verze. git add nazev_souboru (zelené zbarvení)
3. Repozitář (Git Directory / Head) Trvale uložená historie verzí (.git databáze). Každý commit má unikátní hash SHA-1 a autora. git commit -m "zprava"
