📊 Porovnání základních struktur v Pythonu

Základní otázka u maturity: Rozdíl mezi Listem, Tupelem, Slovníkem a Setem.

Struktura Závorky Měnitelnost (Mutable) Duplicity Klíčové použití
List (Seznam) [1, 2, 3] ANO (lze měnit prvky) Povoleny Běžné seznamy položek, fronty, proměnlivá data.
Tuple (n-tice) (1, 2, 3) NE (Immutable konstanta) Povoleny Souřadnice, neměnné konfigurace, návratové hodnoty z funkcí.
Dict (Slovník) {"klic": "hodnota"} ANO Klíče unikátní Mapování dat, JSON API odpovědi, databázové záznamy.
Set (Množina) {1, 2, 3} ANO NE (jen unikáty) Odstranění duplicit, matematické průniky a sjednocení.
