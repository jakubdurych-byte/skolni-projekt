Linuxové jádro, Bash skriptování a Oprávnění

Základ každého serveru, cloudu a maturitní otázky: hierarchie souborového systému (FHS), správa procesů, signály, roury a interaktivní kalkulačka chmod oprávnění.

🔐 Interaktivní kalkulačka unixových práv (chmod)

Klikáním na oprávnění pro vlastníka (User), skupinu (Group) a ostatní (Others) sleduj okamžitý přepočet do osmičkového i symbolického zápisu.

👤 Vlastník (User - u)
👥 Skupina (Group - g)
🌍 Ostatní (Others - o)
Příkaz k nastavení: chmod 754 soubor.sh
Symbolický tvar v ls -l: -rwxr-xr--

📁 Filesystem Hierarchy Standard (FHS) — Kam co v Linuxu patří

/bin & /sbin

Základní binární spustitelné programy pro všechny uživatele (/bin) a správce (/sbin).

/etc

Systémové konfigurační textové soubory (např. /etc/passwd, /etc/nginx/, /etc/hosts).

/home & /root

Domovské adresáře běžných uživatelů a samostatný domovský adresář superuživatele root.

/var & /tmp

Proměnlivá data (logy v /var/log, weby v /var/www) a dočasné soubory mazané po restartu (/tmp).

⚡ Nejdůležitější příkazy, Roury (|) a Přesměrování

# 1. Procházení a zjišťování informací
pwd # Vypíše aktuální pracovní adresář (Print Working Directory)
ls -la # Detailní výpis souborů včetně skrytých (.) a oprávnění
cd /var/log # Změna složky

# 2. Roury (|) a filtrace textu (Grep, Sort, Head, Tail)
cat access.log | grep "404" | wc -l # Spočítá počet chyb 404 v logu
ps aux | grep python # Najde všechny běžící procesy Pythonu

# 3. Přesměrování vstupu a výstupu
echo "Hello" > soubor.txt # Přepíše soubor novým textem
echo "Hello" >> soubor.txt # Přidá (append) řádek na konec souboru
prikaz 2> error.log # Přesměruje chybový výstup (stderr, FD 2) do souboru

# 4. Správa procesů a signály (Kill)
kill -15 PID # SIGTERM: slušné ukončení procesu (uloží si stav)
kill -9 PID # SIGKILL: okamžité násilné zabití jádrem (nelze ignorovat)

📜 Příklad automatizačního skriptu: zaloha.sh

#!/bin/bash
# Skript pro automatické zazipování a zálohu projektu
ZDROJ="/home/student/skolni_projekt"
CIL="/home/student/zalohy"
DATUM="2026-11-10_14-44"

if [ ! -d "" ]; then
  mkdir -p ""
fi

tar -czf "/backup_.tar.gz" ""
if [ 0 -eq 0 ]; then
  echo "[OK] Záloha byla úspěšně vytvořena: backup_.tar.gz"
else
  echo "[CHYBA] Selhalo vytváření archivu!" >&2
  exit 1
fi
