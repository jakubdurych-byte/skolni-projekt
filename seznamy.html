Seznamy (Lists)

Seznamy se v HTML dělí do tří hlavních skupin: odrážkové (nečíslované), číslované (s pořadím) a popisné (pro definice pojmů). Můžeš si přímo v editorech vyzkoušet, co se stane po úpravě kódu.

1.1 Nečíslovaný (<ul>) a číslovaný (<ol>) seznam
HTML Editor (můžeš přepisovat) Živý náhled
Výsledek v prohlížeči
Vysvětlení tagů:
  • <ul> Unordered List – odrážkový seznam. Používá se pro položky, u kterých nezáleží na pořadí.
  • <ol> Ordered List – číslovaný seznam. Prohlížeč k položkám automaticky generuje číslování (1, 2, 3...).
  • <li> List Item – samotný řádek/položka seznamu. Může být pouze uvnitř <ul> nebo <ol>.
1.2 Pokročilé atributy číslování (type, start, reversed)
HTML Editor Živý náhled
Výsledek v prohlížeči
Vysvětlení parametrů:
  • type="1|a|A|i|I" Určuje formát: čísla (1), malá písmena (a), velká písmena (A), malé římské (i), velké římské (I).
  • start="5" Nastavuje počáteční číslo (i když máš písmena, hodnota je vždy celé číslo např. 5 = E).
  • reversed Boolean atribut, který obrátí pořadí číslování sestupně (např. 3, 2, 1).
1.3 Vnořené víceúrovňové seznamy
HTML Editor Živý náhled
Výsledek v prohlížeči
Klíč k vnořování bez chyb:
  • Častá školní chyba: Vnořený seznam se nesmí vložit mezi dvě <li>, ale vždy přímo dovnitř konkrétního <li> před jeho uzavírací značku </li>!
  • Prohlížeč automaticky mění styl odrážek (plný kroužek → prázdný kroužek → čtvereček).
1.4 Popisný / definiční seznam (<dl>, <dt>, <dd>)
HTML Editor Živý náhled
Výsledek v prohlížeči
Vysvětlení struktury <dl>:
  • <dl> Description List: Obaluje celý slovník pojmů nebo seznam párů název-hodnota.
  • <dt> Description Term: Samotný pojem, termín nebo klíč.
  • <dd> Description Details: Popis, definice nebo hodnota pojmu. Může následovat i více <dd> za jedním <dt>.
